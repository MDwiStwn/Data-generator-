# Data Generator Dapodik

Aplikasi web sederhana untuk membuat data dummy (sintetis) untuk kebutuhan pengujian dan simulasi impor data Dapodik (Pegawai, Siswa, dan Tagihan SPP).

### Fitur
- Generate data Pegawai, Siswa, dan Tagihan SPP
- Bisa upload template kustom (Excel/CSV)
- Export data ke Excel (.xlsx), CSV, dan SQL
- Login dengan Google (Gmail)
- Riwayat generate per akun
